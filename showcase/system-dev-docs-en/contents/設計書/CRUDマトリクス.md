[入荷](node:/設計書/データ設計/論理データモデル/入荷)の記録が作成の後に更新も削除もされないのは、それを追記のみのイベントとして持つ[設計判断 D02](node:/設計書/はじめに/設計方針/D02)の帰結である。同じイベント系でも更新が入るものが二つあり、[棚卸](node:/設計書/データ設計/論理データモデル/棚卸)は開始から確定までを棚卸の状態として持つ[設計判断 D05](node:/設計書/はじめに/設計方針/D05)、[販売](node:/設計書/データ設計/論理データモデル/販売)と[販売明細](node:/設計書/データ設計/論理データモデル/販売明細)は保留の販売を店員の確認で登録済みの書籍に結び付ける[設計判断 D04](node:/設計書/はじめに/設計方針/D04)による。
