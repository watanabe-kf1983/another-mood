Sales posting ([UC04](node:/srs/requirements/functional/UC04)), which the payment service initiates, has no screen and is handled within the [external interface requirements](node:/srs/requirements/non_functional/external_interface). Pending sale review ([UC07](node:/srs/requirements/functional/UC07)), which clears up a notification that became pending, is done by a clerk and so has a screen. The two transitions from the delivery registration screen and the pending sale review screen to the book registration screen correspond to the exception "The ISBN is not registered" of delivery registration ([UC03](node:/srs/requirements/functional/UC03)) and the exception "The specified ISBN is not registered" of pending sale review, and the transition from the book registration screen to the book history screen on a duplicate ISBN corresponds to the exception "A book with the same ISBN is already registered" of book registration ([UC01](node:/srs/requirements/functional/UC01)).
