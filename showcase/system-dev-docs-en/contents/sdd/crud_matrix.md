[入荷](node:/sdd/data_design/logical_data_model/delivery)の記録が作成の後に更新も削除もされないのは、それを追記のみのイベントとして持つ[設計判断 D02](node:/sdd/introduction/design_decisions/D02)の帰結である。同じイベント系でも更新が入るものが二つあり、[棚卸](node:/sdd/data_design/logical_data_model/stocktake)は開始から確定までを棚卸の状態として持つ[設計判断 D05](node:/sdd/introduction/design_decisions/D05)、[販売](node:/sdd/data_design/logical_data_model/sale)と[販売明細](node:/sdd/data_design/logical_data_model/sale_line)は保留の販売を店員の確認で登録済みの書籍に結び付ける[設計判断 D04](node:/sdd/introduction/design_decisions/D04)による。
