{#- 付録「業務モデル」の二つのテンプレート (業務モデル.md / 分解図.md) が共有する
    マクロ。マクロの中の substitution はすべて | safe で素のまま出す: マクロの
    戻り値は呼び出し側の {{ }} で改めてエスケープされるので、中でも既定の
    エスケープを掛けると二重になる。呼び出し側は位置に応じて、表のセルなら
    そのまま、Mermaid の中なら | safe を付ける。

    番号 は DFD の慣例 (図 0 の子が 1、2、3、その子が 1.1、1.2、…) をプロセスの
    親子関係と記述順から導く。データには持たない。業務全体 (親を持たない
    プロセス) は 0 で、これは図 0 の番号として使う。

    端 / 上位端 はバランシング検査の比較用で、フローの端 (元 / 先 の 3 択
    オブジェクト) を「種別:ID」の 1 つの文字列に畳む。上位端 は端が親を持つ
    プロセスならその親、そうでなければ端そのもので、下位のフローの端が上位の
    フローの端と対応するか (同一か一段上か) を文字列の比較で確かめる。 -#}
{% macro 番号(p) -%}
{% if p.親 %}
{% set prefix %}{{ 番号(node("プロセス", p.親)) | safe }}{% endset %}
{% for s in node("プロセス") if s.親 == p.親 %}{% if s.id == p.id %}{% if prefix == "0" %}{{ loop.index | safe }}{% else %}{{ prefix | safe }}.{{ loop.index | safe }}{% endif %}{% endif %}{% endfor %}
{% else %}0{% endif %}
{%- endmacro %}
{% macro 表示名(p) -%}
{% if p.親 %}{{ 番号(p) | safe }} {{ p.名前 | safe }}{% else %}{{ p.名前 | safe }}{% endif %}
{%- endmacro %}
{% macro 端名(x) -%}
{% if x.プロセス %}{{ 表示名(node("プロセス", x.プロセス)) | safe }}{% elif x.データストア %}{{ node("データストア", x.データストア).名前 | safe }}{% else %}{{ node("外部エンティティ", x.外部エンティティ).名前 | safe }}{% endif %}
{%- endmacro %}
{% macro 端ノード(x) -%}
{% if x.プロセス %}{{ x.プロセス | safe }}(("{{ 表示名(node("プロセス", x.プロセス)) | safe }}")){% elif x.データストア %}{{ x.データストア | safe }}[("{{ node("データストア", x.データストア).名前 | safe }}")]{% else %}{{ x.外部エンティティ | safe }}["{{ node("外部エンティティ", x.外部エンティティ).名前 | safe }}"]{% endif %}
{%- endmacro %}
{% macro 端(x) -%}
{% if x.プロセス %}プロセス:{{ x.プロセス | safe }}{% elif x.データストア %}データストア:{{ x.データストア | safe }}{% else %}外部エンティティ:{{ x.外部エンティティ | safe }}{% endif %}
{%- endmacro %}
{% macro 上位端(x) -%}
{% if x.プロセス and node("プロセス", x.プロセス).親 %}プロセス:{{ node("プロセス", x.プロセス).親 | safe }}{% else %}{{ 端(x) | safe }}{% endif %}
{%- endmacro %}
