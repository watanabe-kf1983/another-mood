# 画面設計

本システムが利用者に提示する画面を、画面一覧、画面遷移図、および画面ごとの画面定義 (画面レイアウト、入出力項目、アクション) で示す。

分類の メニュー は他の画面へ進むための入口、登録 は入力を受けてデータを作る画面、一覧 は検索して複数件を並べる画面、照会 は 1 件の詳細を表示する画面である。並びはメニューを先頭に、以降は関連ユースケースの順に置く。
