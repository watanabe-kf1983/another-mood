# 画面設計

本章では、本システムが利用者に提示する画面を、画面一覧と画面遷移図で示す。画面は、利用者がユースケースを遂行するための入口であり、各画面がどのユースケースを実現するかを画面一覧の関連ユースケースの列に示す。

## 画面一覧

| ID | 画面名 | 分類 | 関連ユースケース | 説明 |
|----|--------|------|------------------|------|
{% for s in this %}
| {{ s.id }} | {{ s.名前 }} | {{ s.分類 }} | {% for u in s.ユースケース %}{{ node("ユースケース記述", u.ID) | link(u.ID) }} {{ node("ユースケース", u.ID).名前 }}{% if not loop.last %}、{% endif %}{% endfor %} | {{ s.説明 | in_cell }} |
{% endfor %}

分類の メニュー は他の画面へ進むための入口、登録 は入力を受けてデータを作る画面、一覧 は検索して複数件を並べる画面、照会 は 1 件の詳細を表示する画面である。並びはメニューを先頭に、以降は関連ユースケースの順に置く。関連ユースケースの列は要求仕様書のユースケース記述を指す。

## 画面遷移図

```mermaid
stateDiagram-v2
  direction TB
{% for s in this if s.分類 == "メニュー" %}
  [*] --> {{ s.id | safe }}
{% endfor %}
{% for s in this %}
  {{ s.id | safe }} : {{ s.名前 | safe }}
{% endfor %}
{% for s in this %}
{% for a in s.アクション %}
{% for t in a.遷移 %}
  {{ s.id | safe }} --> {{ t.遷移先 | safe }} : {{ a.名前 | safe }}{% if t.条件 %} [{{ t.条件 | safe }}]{% endif +%}
{% endfor %}
{% endfor %}
{% endfor %}
```

矩形が画面、矢印は画面から画面への遷移で、ラベルは遷移を起こすアクション、角括弧はその遷移が起きる条件を表す (条件の無いラベルは、そのアクションで必ず遷移する)。黒丸は起動直後の入口である。画面内で完結するアクション (検索、明細の追加など) は画面を変えないので、この図には現れない。画面がどのユースケースを実現するかは図に描かず、画面一覧の関連ユースケースの列で示す。
