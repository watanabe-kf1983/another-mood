# 論理データモデル

本システムが扱うデータを、ER 図、エンティティ一覧、エンティティ定義で示す。ここで示すのは論理レベルのモデルであり、テーブルの物理定義 (DDL の型、索引、制約の実装) は詳細設計で定める。

## ER 図

```mermaid
erDiagram

{% for a in e.属性 if a.主キー or a.参照 %}
    {{ a.型 | safe }} {{ a.名前 | safe }} {{ ("PK, FK" if a.主キー and a.参照 else ("PK" if a.主キー else "FK")) | safe }}
{% endfor %}
  }
{% endfor %}
{% for e in this %}
{% for a in e.属性 if a.参照 %}
  "{{ e.名前 | safe }}" }o--{{ ("||" if a.必須 else "|o") | safe }} "{{ node("エンティティ", a.参照.エンティティ).名前 | safe }}" : "{{ a.名前 | safe }}"
{% endfor %}
{% endfor %}
```

図に出す属性は主キー (PK) と外部キー (FK) に絞り、残りの属性はエンティティ定義の表に示す。線のラベルは参照する側の属性名である。線の記号は、参照する側が参照先 1 件につき 0 件以上 (鳥の足)、参照される側が、その参照が必須なら必ず 1 件 (二重線)、任意なら 0 件か 1 件 (丸と線) であることを表す。
