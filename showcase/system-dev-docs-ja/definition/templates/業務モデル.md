## 分解図

分解されているプロセスごとに、その子プロセスと、子プロセスが図の外の相手 (外部エンティティ、データストア、他の図のプロセス) と交わすフローを示す。図の外の相手との線は、上位の図で親プロセスの入出力として描かれている線を束ねたもので、各図のフローの表がその対応 (上位のフロー) を持つ。対象は{% for d in this %}{{ d | link("図 " ~ m.番号(node("プロセス", d.id))) }}{% if not loop.last %}、{% endif %}{% endfor %}の {{ this | length }} 枚で、並びはプロセス階層と同じである。

## バランシング検査

分解図の入出力は、上位の図で親プロセスの入出力として描かれたフローと一致していなければならない (バランシング)。分解図ごとに、境界を跨ぐフローが上位のフローを持ちその両端が対応すること、図の中で閉じるフローが上位のフローを持たないこと、親プロセスの入出力がすべて図の中のフローに束ねられていることを確かめる。データストアは業務の内側にあってコンテキスト図には現れないので、データストアとのフローは、そのデータストアが上位の図に描かれているときに限り上位のフローを要する。あわせて、フローの元と先がそれぞれ 1 つの相手に定まることを確かめる。
