# 業務モデル

本システムが支える書店の業務の全体を、階層化したデータフロー図 (DFD) で示す。図の境界は書店の業務であって本システムではない。本システムが担うのは業務の一部で、その境界は設計書のコンテキスト章が描く。コンテキスト図は業務全体を 1 つのプロセスとして外部との入出力を示し、分解図はプロセスを段階的に分解して、各プロセスとデータストア・外部エンティティの間のデータの流れを示す。

外部エンティティは業務の境界の外側の相手であり、本システムのアクター (店員、店主、決済サービス) とは境界が違う。店員と店主は業務の内側にいてプロセスを担い、決済サービスは会計の道具であって業務の相手ではない。

## 分解図

分解されているプロセスごとに、その子プロセスと、子プロセスが図の外の相手 (外部エンティティ、データストア、他の図のプロセス) と交わすフローを示す。図の外の相手との線は、上位の図で親プロセスの入出力として描かれている線を束ねたもので、各図のフローの表がその対応 (上位のフロー) を持つ。対象は{% for d in this %}{{ d | link("図 " ~ m.番号(node("プロセス", d.id))) }}{% if not loop.last %}、{% endif %}{% endfor %}の {{ this | length }} 枚で、並びはプロセス階層と同じである。
