# システム開発ドキュメント

本プロジェクトは、単一のデータソースから「要求仕様書」と「設計書」の二文書を導出する Another Mood のサンプルプロジェクトです。題材は小規模書店の在庫管理システムで、要求仕様書のユースケースや用語を設計書の各章が参照し、片方を直せばもう片方も追随します。現時点では二文書の章立て・導入の文章・用語集に加え、ユースケースとアクターから描く要求仕様書の主要機能・利用者・ユースケース記述と、ユースケースごと・種別ごとに並べる要求と、同じ要求を検証方法・適合基準の側から見直す検証の章、設計書の側から要求仕様書の要求を根拠として参照する設計方針の節、同じユースケースとアクターをシステム境界の図として描き直すコンテキストの章、設計方針の判断がそのまま形になった論理データモデル (ER 図・エンティティ一覧・エンティティ定義)、そのエンティティと要求仕様書のユースケースを掛け合わせた CRUD マトリクス、および本システムが支える書店の業務を階層化したデータフロー図として描き、上位と下位の図の入出力の一致 (バランシング) を検査する要求仕様書の付録の業務モデルと、その業務の単位のうちどれをユースケースが支えるかを導く 1 章の業務コンテキストとシステム化範囲を収録しており、残る章の本文は今後の増分で追加します。

モデルの構造は Database Information (`__db/`) の ER 図と各 Entity Definition ページで参照できます。
