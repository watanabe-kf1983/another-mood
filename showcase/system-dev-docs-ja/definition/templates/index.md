# システム開発ドキュメント

本プロジェクトは、単一のデータソースから「要求仕様書」と「設計書」の二文書を導出する Another Mood のサンプルプロジェクトです。題材は小規模書店の在庫管理システムで、要求仕様書のユースケースや用語を設計書の各章が参照し、片方を直せばもう片方も追随します。現時点では二文書の章立て・導入の文章・用語集に加え、ユースケースとアクターから描く要求仕様書の主要機能・利用者・ユースケース記述を収録しており、残る章の本文は今後の増分で追加します。

モデルの構造は Database Information (`__db/`) の ER 図と各 Entity Definition ページで参照できます。
