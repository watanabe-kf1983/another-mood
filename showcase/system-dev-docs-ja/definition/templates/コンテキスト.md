# コンテキスト

本章では、本システムの境界と、境界の外側の利用者および外部システムとの関連を示す。

```mermaid
flowchart LR
{% for a in node("アクター") if a.種別 == "人" %}
  {{ a.id | safe }}("{{ a.名前 | safe }}")
{% endfor %}
  subgraph 本システム["{{ node(path="/システム").名前 | safe }}"]
{% for uc in this %}
    {{ uc.id | safe }}(["{{ uc.名前 | safe }}"])
{% endfor %}
  end
{% for a in node("アクター") if a.種別 == "外部システム" %}
  {{ a.id | safe }}[["{{ a.名前 | safe }}"]]
{% endfor %}
{% for uc in this %}
{% for a in uc.アクター %}
  {{ a.ID | safe }} --- {{ uc.id | safe }}
{% endfor %}
{% endfor %}
```

箱で囲った範囲が本システムの境界で、中に並ぶのが本システムの担うユースケース、外にあるのが本システムを操作する利用者と、本システムと連携する外部システム (二重の縦線) である。線は、そのユースケースに関わるアクターを結ぶ。本システムが担うのは境界の中だけで、利用者の業務のうち境界の外で行われることは本システムの責任範囲ではない。

各ユースケースの内容は要求仕様書の{{ node("ユースケース") | link("主要機能") }}とその機能要求の節に、境界を跨ぐ連携そのものへの要求は{{ node("要求種別", "外部インタフェース") | link("外部インタフェース要求") }}にある。
