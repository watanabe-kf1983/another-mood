対応する用語を持たないのは、業務の言葉では親の一部として語られる明細のエンティティ ([入荷明細](node:/エンティティ/入荷明細)、[販売明細](node:/エンティティ/販売明細)、[棚卸明細](node:/エンティティ/棚卸明細)) である。

[販売](node:/エンティティ/販売)と[販売明細](node:/エンティティ/販売明細)を参照する画面が無いのは、販売が決済サービスからの通知として入り、利用者が画面から登録する対象ではないためである。この二つを表示する[書籍履歴画面](node:/画面/SC07)も、入荷・販売・棚卸の三種を一つの履歴の表に畳んでいるので、項目の参照先を定めていない。
