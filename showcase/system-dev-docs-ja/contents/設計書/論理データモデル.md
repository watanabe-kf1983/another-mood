対応する用語を持たないのは、業務の言葉では親の一部として語られる明細のエンティティ ([入荷明細](node:/エンティティ/入荷明細)、[販売明細](node:/エンティティ/販売明細)、[棚卸明細](node:/エンティティ/棚卸明細)) である。

[販売](node:/エンティティ/販売)と[販売明細](node:/エンティティ/販売明細)を画面から登録することはない。販売が決済サービスからの通知として入るためで、この二つを参照する画面は、通知に未登録の書籍が含まれて保留になったときの[保留販売確認画面](node:/画面/SC08)だけである。同じ二つを表示する[書籍履歴画面](node:/画面/SC07)が項目の参照先を定めていないのは、入荷・販売・棚卸の三種を一つの履歴の表に畳んでいるためである。
